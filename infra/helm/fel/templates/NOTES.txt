Select the same kubeconfig and context used to install this release.
For lab.sh, set these in your shell first:
  export FEL_KUBECONFIG="${FEL_LAB_STATE:?Set the lab state directory}/kubeconfig"
  export FEL_KUBE_CONTEXT="kind-${FEL_LAB_CLUSTER:-fel-helm-lab}"
For another cluster, set FEL_KUBECONFIG and FEL_KUBE_CONTEXT to its explicit target.
The commands below refuse unset or empty targets instead of using your default cluster.

Local fixture UI:
  kubectl --kubeconfig "${FEL_KUBECONFIG:?Set the installation kubeconfig}" --context "${FEL_KUBE_CONTEXT:?Set the installation context}" -n {{ .Release.Namespace }} port-forward service/{{ include "fel.fullname" . }}-web 3000:3000 --address 127.0.0.1
  Open http://127.0.0.1:3000
